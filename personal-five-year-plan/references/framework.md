# 国家五年规划范式 → 个人版框架对照

## 一、国家规划的核心逻辑

中国国民经济和社会发展五年规划（纲要）的编制与实施，本质是一套**「目标管理 + 滚动评估」**的中长期治理机制：

1. **顶层设计**：提出五年发展定位与远景目标（总纲）；
2. **指标体系**：区分**约束性指标**（政府必须完成的硬指标，如环保、民生保障）与**预期性指标**（引导市场、允许浮动，如 GDP 增速）；
3. **重点任务**：分领域部署任务（产业、科技、民生、生态等）；
4. **重大工程**：集中资源实施标志性工程（如重大科技专项、基础设施建设）；
5. **保障与风险**：财政、金融、政策保障与风险防范；
6. **评估调整**：年度评估 + **中期评估**（第 2.5 年，可调整指标与任务），期末评估并衔接下一轮。

个人规划可完整移植这套结构，解决个人规划常见的三大问题：目标虚浮不可量化、没有底线约束、写完就忘没有评估机制。

## 二、术语映射表

| 国家规划要素 | 个人版要素 | 说明 |
| --- | --- | --- |
| 发展定位、远景目标 | 五年总纲 | 一句话：5 年后你是谁 + 核心目标 + 底线 |
| 约束性指标 | 约束性指标（红线） | 必须完成，原则上不可改动；数量 3–5 条 |
| 预期性指标 | 预期性指标（奋斗目标） | 努力争取，中期评估可上调/下调；数量 5–8 条 |
| 重点领域任务 | 五大领域任务 | 人力资本 / 经济与资产 / 健康民生 / 社会关系 / 生活与精神 |
| 重大工程 | 重大专项工程 | 集中资源攻坚 1–2 年、完成后跃迁；2–4 个 |
| 风险防范与保障 | 风险清单与资源储备 | 职业 / 财务 / 健康 / 时间冲突，各配预案 |
| 年度评估 + 中期评估 | 年度复盘 + 2.5 年中期评估 | 中期可改预期指标与专项，约束指标原则上不动 |
| 五年滚动衔接 | 期末评估 → 下一轮五年规划 | 第 5 年末总结，起草下一份纲要 |

## 三、指标分类规则（核心）

**约束性指标**判定标准（满足任一即倾向约束）：
- 涉及健康、安全、债务等**不可逆或高代价**的事项（如：不逾期负债、每年体检、每周运动次数）；
- 一旦失守会**连锁破坏其他目标**（如：强制储蓄红线，失守则财务目标整体崩塌）；
- 用户明确表示"无论如何都要做到"的事项。

**预期性指标**判定标准：
- 受外部环境影响较大（收入、行业机会、市场行情）；
- 达成与否不构成系统性风险，允许中途调整；
- 通常与"想成为谁"的愿景直接相关（技能等级、作品数量、影响力）。

规则：约束性指标要少而硬（3–5 条），预期性指标可多可活（5–8 条）；两者都必须是**可量化、可验证**的，禁止纯定性表述。

## 四、重大专项工程判定标准

- 需要**持续投入大量时间或资金**（不是日常例行事项）；
- **1–2 年攻坚期**，完成后能力/资产/状态跃迁一个台阶；
- 与五年总纲直接相关，属于"不集中资源就做不成"的事。

反例（不算专项）："每周读书"是领域任务；"从零转型 AI Agent 开发并产出可交付作品集"才是专项。

## 五、评估机制设计

| 评估时点 | 做什么 | 可调整项 |
| --- | --- | --- |
| 每年年末 | 对照指标打分（达标/部分/未达标），复盘归因 | 下一年度任务、专项里程碑 |
| 第 2.5 年（第 3 年年初） | 中期大评估：重审总纲与资源配置 | 预期性指标、重大专项（增删/改），**约束性指标原则上不改** |
| 第 5 年年末 | 期末评估：全面复盘，总结经验教训 | 起草下一轮五年规划 |

评估输出的核心动作：**对照指标 → 找偏差 → 归因（内部/外部）→ 决定调整还是坚持 → 更新文档**。

## 六、文档结构建议

《个人五年规划纲要》建议固定章节顺序，便于逐年修订：
总纲 → 指标表 → 领域任务 → 专项工程 → 风险预案 → 评估机制 → 首年拆解（年度目标 + 季度 OKR）。
季度 OKR 按主题拆分为每季度 2–4 个 O、每个 O 挂 2–3 个可验证 KR，禁止多主题聚合进单个 O。
