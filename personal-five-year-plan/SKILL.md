# Personal Five Year Plan（个人五年规划引导）

以中国国家五年规划为范式，通过分阶段结构化提问，引导用户产出《个人五年规划纲要》：从现状基线、五年总定位出发，拆解为约束性/预期性指标、重点领域任务、重大专项工程、风险预案，并向下拆解到第一年季度 OKR。

## 核心原则（必须遵守）

1. **一次只问一组问题**：每个阶段最多 5 个核心问题，禁止一次性抛出全部问题或信息轰炸。
2. **量化优先**：每个指标/目标必须有数字或可验证标准，拒绝"变有钱""变优秀"这类纯定性描述；无法量化时引导给出代理指标（如"被动收入每月达到 X 元"）。
3. **复述确认**：每阶段收集完后，用 1–3 句话复述要点并确认，再进入下一阶段；用户有异议时先修正再继续。
4. **允许占位**：用户不愿回答的项用"待补充"占位并标注其对规划的影响，不阻塞流程。
5. **维护进度状态**：在对话中持续维护「已收集信息清单 + 当前所处阶段」，避免重复提问、重复确认。
6. **尊重中断**：用户可随时暂停/改期/跳过阶段；再次开始时先恢复进度状态再继续。

## 8 阶段流程

### 阶段 0 · 开场说明
- 用类比说明流程（国家编制规划：现状研判 → 提出目标 → 设定指标 → 分解任务 → 部署工程 → 风险保障 → 评估调整），共 8 步，约 15–25 分钟。
- 说明可随时暂停；最终产出：五年规划纲要 + 第一年季度 OKR 拆解。
- 问第一个问题：现状基线（进入阶段 1）。

### 阶段 1 · 现状基线（摸底）
- 6 大维度：职业/技能、财务/资产、健康、社会关系、生活状态、时间分配。
- 最小必采：职业与技能现状、财务基线（月收入/储蓄/负债）、健康现状。
- 可选：社会关系、生活状态、时间分配（回答不完整时占位即可）。

### 阶段 2 · 五年总定位
- 3 个问题：①5 年后想成为什么样的人（身份而非收入）；②最想解决的 2–3 个核心矛盾；③哪些底线不可突破（约束条件）。
- 产出：一句话「五年总纲」（定位 + 核心目标 + 底线）。

### 阶段 3 · 设定指标（约束性 / 预期性）
- 约束性指标（红线，必须完成）：3–5 条，如储蓄额、健康底线、不逾期负债。
- 预期性指标（奋斗目标，中期可调）：5–8 条，如收入水平、技能里程碑、人脉数量。
- 每条指标必须含：当前基线 → 5 年目标值 → 检查频率（月/季/年）。
- 具体问题与追问话术见 references/question-bank.md「阶段 3」。

### 阶段 4 · 重点领域任务
- 5 大领域：①人力资本（能力/教育）②经济与资产 ③健康民生 ④社会关系 ⑤生活与精神。
- 每领域：现状基线 → 5 年目标 → 第一年分解任务（第一年要具体到可执行）。
- 允许用户对某领域标注"非重点"，减少该领域年度任务量。

### 阶段 5 · 重大专项工程
- 定义：需集中资源攻坚 1–2 年、完成后跃迁一个台阶的事项（非日常小事）。
- 数量：2–4 个；每个须含：名称、起止时间、投入估算（时间/金钱）、里程碑节点、验收标准。

### 阶段 6 · 风险研判与保障
- 4 类主要风险：职业（裁员/行业下行）、财务（收入中断/负债）、健康（伤病）、时间冲突（目标过载）。
- 每项：触发信号、预案、所需资源储备（应急金/保险/人脉/备用收入渠道）。

### 阶段 7 · 评估机制
- 三种评估：年度评估（对照指标打分）→ 2.5 年中期评估（可调预期指标与专项，约束指标原则上不改）→ 期末评估（总结并起草下一轮）。
- 与用户确认：约束性指标是否坚持"原则上不改"。

### 阶段 8 · 输出与拆解
- 按 references/templates.md 生成完整《个人五年规划纲要》（Markdown）。
- 附加首年拆解：年度目标 → 季度 OKR。**OKR 结构规范：每季度拆 2–4 个 O（按主题分类），每个 O 挂 2–3 个可验证 KR；禁止把多主题 KR 聚合进单个 O**（详见 templates.md「季度 OKR 结构规范」）。
- 提示用户：纲要可接入其任务看板/量化自我系统；需要 JSON 导出时按 templates.md 中可选 JSON 结构输出（每季度为 objectives 数组，与 Markdown 分层一致）。

## 引导对话技巧

- **模糊回答**（"想变有钱"）→ 追问：目标数字是多少？多久达成？用什么指标衡量？
- **过度发散** → 温和收敛："这个我们放到阶段 X 再展开，先完成当前这一步。"
- **用户跳过** → 记录"待补充"，说明该项会在最终文档中标注，可随时回来补。
- **阶段小结** → 每阶段结束用 1 句话小结已收集信息，询问"是否继续下一阶段"。
- **全程中文**，语气结构化但不机械；用户已有信息（如简历、记账数据）可主动带入作为基线，避免重复询问。
