# see_self · 产品文档

> 面向使用者：介绍项目能做什么，不含任何技术实现细节。

## 项目定位

see_self 是一套**个人五年计划管理系统**：像国家制定「五年规划」一样管理自己的人生，把长期目标逐层拆解到每天的具体行动，并用一个实时看板量化「时间正在流逝、任务推进了多少」，对抗「稀里糊涂一周/一月就过去了」的生活惯性。

## 核心规划模型

系统按四层结构组织目标：

```
五年计划（人生总纲）
  └─ 季度 OKR（阶段性目标）
       └─ 项目（具体交付物）
            └─ 待办（可多级嵌套的事项）
```

- 上下层挂靠全部可选：允许存在独立的 OKR、独立项目；
- 删除上层会自动级联清理其下所有内容（页面有二次确认）；
- 上层进度由下层实时汇总，无需手动维护。

## 功能总览

### 首页监控看板（纯查看，不提供写入口）

- **时间流逝可视化**：毫秒级实时时钟；年 / 月 / 日三条进度条（今日为实时百分比），直观展示今年、本月、今天已过去多少；
- **推进数据监控**：推进热力图（近三月、全站每日推进量，GitHub 色阶）+ 数据仪表盘（累计完成 / 本月完成 / 日均完成三个大数字）；
- **项目推进可视化**：项目卡片展示分段进度条、「本月 / 本周 / 昨日 / 今日」推进量与完成数（已完成 / 总数），点击卡片即可进入该项目进度视图。

### 五年计划管理

- 系统只维护一份五年计划，通过导入「个人五年规划纲要」文件整体加载，已存在则整体覆盖；
- 完整的规划纲要结构：五年总纲（定位 / 核心目标 / 底线约束）、指标体系、重点领域任务、重大专项工程、风险研判与保障、评估机制、待补充清单；
- 首年拆解：年度目标 + 季度 OKR，可继续往下挂项目与待办。

### 季度 OKR 管理

- 按季度管理目标（Objective）与关键结果（Key Results），可选择挂靠五年计划。

### 项目与待办管理

- 项目列表 + 项目详情：待办按「模块 → 事项」两层组织，完成时可记录要点子记录；
- 完成状态一目了然，支持随时切换完成 / 未完成。

### 项目进度视图

- 阶段轨道、项目进度曲线（日期 × 进度% 平滑曲线，加载生长动画）、开发日志（按日期聚合的项目 · 模块完成记录）、下一步事项（支持快捷完成、本地实时更新），直观看到项目推进节奏与近期活跃度。

### 数据备份导出

- 一键导出全部数据（JSON / CSV），方便备份与迁移。

### 设置

- 时区、外观（自定义背景图）等个性化设置。

### AI 助手接入

- 支持通过 AI 智能体（Agent）读写全部数据：查看 / 创建 / 修改 / 删除五年计划、OKR、项目、待办，支持整体导入与批量操作，与网页端数据完全同步。

## 适合谁用

- 想把长期目标（学习、职业、健康、财务等）系统化、可量化推进的人；
- 喜欢用「规划 + 复盘」方式管理自己，需要把目标拆到每天可执行的人；
- 想用 AI 协助管理个人规划、通过对话或自动化维护数据的人。
