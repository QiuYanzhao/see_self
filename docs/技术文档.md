# see_self · 技术文档

> 面向开发 / AI 维护者：技术栈、系统架构、目录梳理与模块定位，方便快速定位代码。

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python 3.12 · FastAPI · Uvicorn | 异步 API，自带 OpenAPI 文档（/docs） |
| ORM / 迁移 | SQLAlchemy 2.0 · Alembic | 方言无关，SQLite / MySQL 同一套代码 |
| 校验 | Pydantic v2 | 请求 / 响应模型 |
| MCP | FastMCP | stdio / streamable-http 双模式，暴露 25 个 `seeself_*` 工具 |
| 前端 | Vue 3 · Vite · TypeScript · Pinia · Vue Router | SPA |
| 数据库 | 生产 MySQL（库 `see_life`）；本地 / 测试 SQLite | 连接串由根目录 `.env` 的 `DATABASE_URL` 决定 |
| 依赖管理 | uv（后端）/ pnpm（前端） | |

## 系统架构

```
┌────────────────────────────────┐
│  frontend/  Vue3 SPA（7 个页面） │
└──────────────┬─────────────────┘
               │ /api  （dev: Vite proxy :5173 → :8080）
┌──────────────▼─────────────────┐
│  src/seeself/  FastAPI          │
│  routers/（薄 JSON API）        │
│      │                          │
│      ▼                          │
│  services/（业务逻辑唯一实现）   │
│      ▲                          │
│  mcp_server.py ──► services/    │  25 个 seeself_* 工具共用同一 Service
│      │                          │
│      ▼                          │
│  models.py（SQLAlchemy ORM）    │
└──────────────┬─────────────────┘
               │
      MySQL（生产）/ SQLite（本地）
```

要点：

- **单一业务入口**：Web API 与 MCP 工具共用同一套 Service 层，口径一致，改一处两边生效；
- **单端口部署**：生产模式 `vite build` 产物由 FastAPI 托管（SPA history 回退），一个进程即可跑完整应用；
- **方言无关**：模型全部使用通用列类型，SQLite 自动开启外键级联，MySQL 走 InnoDB，业务代码不写方言 SQL。

## 数据模型

主链：`five_year_plan → okr → project → todo`，删除时由应用层级联清理；`todo` 通过 `parent_id` 自引用组成树（产品形态为「模块 → 事项」两层），`todo_note` 存完成时的要点子记录。

| 表 | 说明 | 关键字段 |
|---|---|---|
| `five_year_plan` | 五年计划（低密度纲要结构存 JSON 字段） | name, start_year, end_year, vision_* |
| `plan_indicator` | 指标体系（约束性 / 预期性） | kind, name, baseline, target |
| `plan_domain` | 重点领域任务 | domain, five_year_target, year1_tasks |
| `plan_special_project` | 重大专项工程 | name, milestones, acceptance_criteria |
| `plan_risk` | 风险研判与保障 | risk_type, trigger, plan, reserve |
| `okr` | 季度 OKR | quarter, objective, kr_results |
| `project` | 项目 | okr_id, name |
| `todo` | 待办（树） | parent_id, title, sort_order, completed_at |
| `todo_note` | 待办子记录 | content |
| `app_setting` | 全局设置 KV | key, value |

## API 一览

| 模块 | 端点 |
|---|---|
| 看板 | `GET /api/dashboard`、`GET /api/health` |
| 五年计划 | `GET/POST /api/plans`、`PUT/DELETE /api/plans/{id}`、`POST /api/plans/import` |
| OKR | `GET/POST /api/okrs`（`?plan_id=`）、`PUT/DELETE /api/okrs/{id}` |
| 项目 | `GET/POST /api/projects`（`?okr_id=`）、`PUT/DELETE /api/projects/{id}` |
| 待办 | `GET /api/todos/tree/{project_id}`、CRUD、`PUT /{id}/toggle`、notes、`/progress`、`/heatmap`（项目）/`timeline` `/pending`；`GET /api/todos/heatmap`（全站） |
| 设置 | `GET/PUT /api/settings` |
| 导出 | `POST /api/export?fmt=json\|csv` |

## 常用命令

```bash
uv sync --extra mysql --extra dev              # 安装依赖（含 MySQL 驱动与开发依赖）
uv run python scripts/init_mysql.py            # 生产：初始化 MySQL see_life（幂等）
uv run alembic upgrade head                    # 离线 / 测试：SQLite 建表
uv run uvicorn seeself.main:app --port 8080 --reload   # 启动 API
uv run pytest -q                               # 运行测试
bash scripts/dev.sh                            # 本地服务管理（默认端口 8089）
cd frontend && pnpm install && pnpm dev        # 前端开发模式（5173）
cd frontend && pnpm build                      # 前端构建（产物由后端托管）
uv run python -m seeself.mcp_server            # MCP stdio
uv run python -m seeself.mcp_server --transport streamable-http --port 8765   # MCP HTTP
```

## 关键设计说明

- **进度实时聚合、不落库**：项目进度 = 叶子待办完成数 / 总数；按「月初前 / 月初→周初 / 周初→昨日 / 昨日 / 今日」五个时间快照切成分段，读取时实时计算，无冗余存储；
- **关联与级联删除在应用层维护**：数据库表已去除外键约束（`scripts/sql` 同步），删除 OKR / 项目时由 Service 手动清理其下待办与子记录；ORM 模型保留外键映射用于关系查询；
- **MCP 与 Web 同源**：同一 Service 层 + 同一数据库，AI 写入的数据页面立即可见；
- **连接池（MySQL）**：`pool_pre_ping` + `pool_recycle=1800`，避免空闲连接被服务端回收后报错。
